## 追加：KPI 卡片不显示的修复 + 钻取（用户反馈「这里没有看到对应的KPI卡片」）

### 根因

`kpiStrip()` 首行是 `if(!db.tasks.length)return ""` —— 我上次自己定的「空库不显示四个 0」，而用户那边库是空的（侧栏「全部任务 0」），所以整条被跳过。截图位置/白名单都没问题（`KPI_VIEWS` 含 `today`）。

### 修复与增强（`src/index.html`）

- `kpiStrip()` **去掉空库守卫**，始终渲染；**计数为 0 的卡片置灰 `disabled` 且不带状态色**（颜色只表示"这里有事看"）。
- `.kpi` 由 `div` 改为 `button`：补 `font:inherit / text-align:left / width:100%`，加 hover（`--line2` + `--shadow-2` + 上移 1px）、`:disabled`（opacity .5）、`.on`（`--pri` 边框 + `--ring`）。
- **卡片即入口**：新增 `ui.kf`（`all`/`todo`/`od`/`doing`/`done`），点卡片钻到「任务」页并按该口径过滤，再点一次取消；`KF_LABEL` 提供中文名。
- 新增 `kpiFiltered()`（叠加在 `filtered()` 之上）——`viewAll()` 列表路径与 `boardTasks()` 看板路径共用，**看板也吃这个口径**。
- 新增 `kfChip()`：任务页筛选条里显示一枚可关闭的钻取芯片，`filterBar()` 与 `boardFilterBar()` 共用；看板的「清空筛选」按钮显隐条件也带上 `ui.kf`。
- `bprojClear` 动作现在一并重置 `ui.kf`。
- `viewAll()` 重写：钻到「已完成」时已完成区当主角（不再出现「进行中」空块）；钻到待办/逾期/进行中时只列未完成且标题变成对应口径名；新增 `activeFilterNames()` + `filteredEmpty()`，空结果时明说「当前生效的筛选：逾期、优先级 高」而不是笼统一句。

### 踩到的坑（重要）

同一条消息里对同一文件**并行发两个 Edit**，后写的覆盖先写的，`filterBar()` 那处改动静默丢失（工具仍回 success）。发现方式是 grep 构建产物：`dist/assets/*.js` 里 `sr(){...'class="fbar"'+Un()...}` 只调 `priChips` 没有 `kfChip`。教训已写入 MEMORY.md：**同文件多处修改串行发 + 改完 grep 产物确认**。
