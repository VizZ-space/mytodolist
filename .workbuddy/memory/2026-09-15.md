## 追加：Esc 未逐层退（第六轮反馈）

**用户反馈**：「选择日期这里按 esc 直接关闭弹窗了，而不是返回打开日期之前」。

### 根因（重要，影响以后所有浮层）

三个 `document` keydown 监听器抢同一次按键，**同一元素上的多个监听器互不阻塞**，`return` 只结束自己那一个：

| 注册顺序 | 监听器 | 作用 |
|---|---|---|
| 1 | `if(DP&&Escape)closeDatePicker()` | 关日期面板 |
| 2 | `if(USOPEN&&Escape)closeUse()` | 关自定义下拉 |
| 3 | 主处理器 `if(Escape){closeModal();...}` | 关弹窗 |

于是按一次 Esc 面板和弹窗全关；且顺序上 ① 先把 `DP` 清成 null，主处理器里再加「浮层还开着吗」的守卫**恒为假**（第一次这么修，UI2 实测仍 FAIL）。

### 修法：收敛成唯一权威处理器

- **删掉** `#dp`、`#uselpop` 各自的 keydown 监听器
- 全局处理器里按层级顺序：`DP` → `USOPEN` → `closeModal()`（放在命令面板、子任务行内编辑分支之后）

### 验证

- 冒烟 **37/37 / 0 条 JS 错误**，新增 UI2：日期面板 Esc 只收面板（弹窗仍在）／项目下拉同样／浮层都收了再 Esc 才关弹窗／再重开弹窗
- 审计五类全 0（5185 行，496 类）
- 截图 `date-picker.png` / `after-esc-date.png` 人工确认

### 顺带修掉的脚本 bug：modal-audit 被入场动画骗了

跑 `modal-audit.mjs` 报了 5 个弹窗"宽度不在阶梯上"，值是 **709 / 552 / 867** —— 恰好是 720 / 560 / 880 × **0.985**。查出来是 `.sheet` 的入场动画 `sheetIn{from{transform:scale(.985)}}`：脚本只 `sleep(420)` 就量 `getBoundingClientRect()`，机器负载高时动画没播完，量到缩放中间值。

**修法**：测量前把动画推到终点，而不是把 sleep 调大（调大只降低概率）：

```js
s.getAnimations({subtree:true}).forEach(function(a){try{a.finish()}catch(_){}});
```

**教训**：**用 `getBoundingClientRect()` 做尺寸断言，必须先中和 CSS 动画/过渡**。`transform` / `opacity` 有入场动画的元素，rect 在动画期间都是"中间值"，而且这种失败**只在慢机器上偶发**，最容易被当成"上次还好好的"忽略掉。

| 面板里的东西 | 别处有吗 |
|---|---|
| 标题 | 卡片上就是（而且卡片是全文） |
| 状态 / 优先级 / 重要 / 截止 芯片 | 卡片 `.chips` 里全有 |

### 两个可复用的经验

1. **删整块代码时用「锚点切块 + 断言命中」，不要手抄几十行 `old_string`，也不要记行号。** 本轮删 CSS 区块用两条注释当锚点（`right inspector` → `顶部 KPI 卡片`），删 JS 函数用 `function inspTask(t){` → `/* 笔记模块 */`；脚本里每步都 `must(命中1次)`，不满足就整体不写盘。理由：行号会因为前面的删除全变，而手抄 70 行 old_string 几乎必错。**反面教材就在同一轮：有处 Edit 我把 `new_string`/`old_string` 的方向写反了，把 `if(ui.selId)` 那行变成重复两行** —— 所以脚本里还要加一条"删完之后 grep 残留"的总断言（本轮它真的拦下了一次：`edit` 动作里还有一处 `renderInsp()` 未清）。
2. **新增断言要连"前置条件"一起断言。** IA7 想验的是"项目推导为空 → 沿用任务原值"这条分支，如果随便挑一张带客户的卡，而那张卡恰好有项目芯片，用例就**PASS 但什么都没验**（空转）。所以脚本先挑"有客户且无项目芯片"的卡，并要求 `pick.noProj === true`，否则直接判失败并说明"用例会退化成空转"。这是本项目"退化而非报错"那类坑的通用解法。
