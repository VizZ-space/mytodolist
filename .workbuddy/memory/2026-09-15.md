# 2026-09-15 工作日志

## 信息架构重构：今天 / 任务 / 看板 三入口去重

用户反馈「今天」和「任务」都是待办事项的入口，重复；并希望把看板提到最上方。

### 落地内容（`src/index.html`）

- 新增 `ui.taskMode`（`"list" | "board"`），默认 `"list"`。
- 新增 `taskModeSwitch()`：渲染在**任务页最上方**（在 quickAdd / 筛选条之前）的 `列表 | 看板` segmented 切换器，是进入看板的唯一入口。复用既有 `.seg` 组件 + 新增 `.tmode-head / .tmode-seg` 样式。
- **导航移除「看板」**：`NAV_MORE` 从 5 项降为 4 项（四象限 / 历史 / 总览 / 报告），`NAV_ALL` 变 9 项，快捷键 1–9 顺延（6=四象限 7=历史 8=总览 9=报告）；移动端 tabbar 同步。
- 删除 `viewBoard()`，其能力并入 `viewAll()`：`viewAll` 顶部切换器 → quickAdd → `boardFilterBar()`/`filterBar()` → `kanban(boardTasks())` / 列表。
- 命令面板（⌘K）的「看板」项改为 `ui.view="all" + ui.taskMode="board"`；「任务」项强制 `taskMode="list"`。
- `kanban()` 去掉重复的「任务看板」标题与说明（已由顶部切换器承担）。
- **「今天」瘦身**：去掉 `filterBar()`（优先级筛选）与底部「进行中的任务」全量列表（那是任务页的内容），改为一行引导 `.today-more`：「去『任务』看全部 N 项进行中」。今天只保留时间焦点：今天要处理 / 逾期批量治理 / 近 3 天 / 久未跟进 / 已完成入口。删除 `.today-rest` 三条孤儿 CSS。
- **筛选条收敛**：抽出 `priChips()`，`filterBar()` 与 `boardFilterBar()` 共用同一份优先级芯片（原先看板模式下的芯片没有颜色，与列表不一致）。同时把 `p-high/p-mid/p-low` 由字符串拼接改为字面量，消除静态审计的 3 条误报。
